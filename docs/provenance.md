# Source and validation provenance

The RTL was copied from the student submission and matched byte-for-byte with the working RTL on the course server. SHA-256 of `rtl/IOTDF.v` is `7643ffd3b4af91bd8b41ce7a3bd6f4e3f23179786b6d735d3e750ed76c9fd28a`. The pattern files come from the corresponding course testbed. `constraints/interface.sdc` preserves the source timing and I/O assumptions with technology selection removed.

The archived synthesis output directory contains `IOTDF_syn.v`, `IOTDF_syn.sdc`, `IOTDF_syn.sdf` and `IOTDF_syn.ddc`. The mapped design contains inserted Synopsys clock-gating wrappers and technology cell instances. The generated timing constraints select a library operating condition. SDF records instance timing; DDC is a compiled tool database. The reviewed mapped netlist is included in this private repository at `synthesis/IOTDF_syn.v`. Its only definitions are the IOTDF top and six one-instance clock-gate wrappers. All technology cell models remain external, and a gate simulation requires those authorized models. The paired private `synthesis/IOTDF_syn.sdf` was reviewed as a design-level SDF delay file. Its 3,575 instance records annotate this mapped IOTDF design, and all 126 referenced cell types appear in the mapped Verilog. It provides delays and timing checks, and requires external cell models to run. The generated SDC and binary DDC remain in the course archive pending artifact-specific review. The portable tests operate on RTL with no foundry library dependency.

GitHub Actions runs the same local Make regression on pushes and pull requests. The values in the README referring to the original report describe that submission.
